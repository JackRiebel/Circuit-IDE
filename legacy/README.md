# Legacy archive

This directory contains retired, unsupported implementations and historical
documentation retained only for migration research. It is not a release target
and it is excluded from the CircuitCode product build and CI gate.

The supported application is the Flutter macOS desktop product in
[`../circuit-ide/`](../circuit-ide/). Use the repository-root
[`../circuit-ide.command`](../circuit-ide.command) launcher or the Flutter
commands documented in the root README.
