# Studio Module Size Exceptions

`circuit-ide/scripts/verify_studio_module_size.sh` enforces an 800-line limit
for Studio UI modules and a 1,000-line limit for state providers.

There are currently no approved exceptions. A future exception must name the
exact relative source path in backticks, its owner, a technical reason, and a
dated removal plan. Exceptions are temporary; they do not waive CC-ARCH-003.
